# School Database Management System

A desktop application developed using C# Windows Forms and SQL Server. This project was completed in 2024 as my first software development project.

## Features

* Student Registration
* Lecturer Registration
* Course Registration
* Student Marks Calculator
* Record Management (Add, Update, Delete, Search)

## Technologies Used

* C#
* Windows Forms
* SQL Server
* Visual Studio

## Learning Outcomes

This project helped me gain practical experience in database connectivity, CRUD operations, user interface design, and desktop application development. It also strengthened my interest in Computer Science and software development.
