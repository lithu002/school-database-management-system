# School Database Management System

A desktop application developed using C# Windows Forms and SQL Server.
This was my first software development project, completed in 2024.

## Features

- Student Registration
- Lecturer Registration
- Course Registration
- Student Marks Calculator
- Record Management (Add, Update, Delete, Search)

## Technologies

- C#
- Windows Forms
- SQL Server
- Visual Studio

## Learning Outcomes
This project helped me understand database connectivity, CRUD operations, user interface design, and desktop application development.
